== Maintainability criterion

Every implementation issue must leave a useful Rust file structure: crate roots remain thin, production concerns are split into cohesive modules, and tests live in dedicated test modules where practical. Keep source files at or below 500 lines as a soft guideline. A file above 500 lines should trigger a split review; retain it only when the module is genuinely cohesive and the exception is documented. `cargo fmt --check` and `cargo test` must remain green after structural changes.
