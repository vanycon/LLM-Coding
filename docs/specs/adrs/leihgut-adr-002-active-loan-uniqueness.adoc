= ADR-002: Database Uniqueness for Active Loans

== Status

Accepted in the current implementation.

== Context

Two concurrent attempts must not create active loans for the same item. The schema defines a partial unique index on `gegenstand_id` where the loan state is active, and the SQLite loan repository uses an explicit transaction/check-then-act path. Evidence: `src/leihgut/adapters/persistence/schema.sql::ux_ausleihe_aktiv_je_gegenstand` and `src/leihgut/adapters/persistence/sqlite_ausleihe_repository.py`.

== Decision

Enforce the one-active-loan-per-item invariant in the database with `ux_ausleihe_aktiv_je_gegenstand`, in addition to application-level validation and the repository transaction path.

== Consequences

The invariant remains protected below the application layer, including against a race between application checks. A database-specific constraint and its error handling remain part of the persistence adapter contract.
