= ADR-001: Ports and Adapters with an Exchangeable Clock

== Status

Accepted in the current implementation.

== Context

The application core is separated into domain models, application services, Protocol ports, and adapters. Time must be replaceable so deadlines and timestamps can be tested. Evidence: `src/leihgut/ports/clock.py`, `src/leihgut/adapters/system_clock.py::SystemClock`, `tests/fakes.py`, and dependency injection in `src/leihgut/adapters/rest/app.py::create_app`.

== Decision

Use a hexagonal/modular structure. Keep repository and clock contracts in `src/leihgut/ports/`; provide SQLite and system-clock implementations under `src/leihgut/adapters/`; inject the clock and repositories when creating the application.

== Consequences

The application core can be tested with fake infrastructure and can preserve its contracts when an implementation satisfies the Protocols. The current deployment remains Python plus SQLite, and the source does not define a different production persistence target.
