== Description
Implement category-based hold queues, three-calendar-day reservations, allocation, expiry, and suspended-member queue preservation.

== Acceptance Criteria
[source,gherkin]
----
Given members hold positions in a category queue
When an item becomes available or a reservation expires
Then the first eligible member receives the reservation
And suspended members are skipped without losing or changing queue position
And maintenance-due items are never reserved
----
