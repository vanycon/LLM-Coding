== Description
Implement eligibility, issue, extension, and counter return as one coherent lending lifecycle. A return moves an item into inspection and does not complete the loan.

== Acceptance Criteria
[source,gherkin]
----
Given a catalog and member state satisfying the domain rules
When clerks perform eligibility, issue, extension, and return operations
Then each operation applies its specified state transitions
And rejected state-changing operations leave domain and ledger state unchanged
----
