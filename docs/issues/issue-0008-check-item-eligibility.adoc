== Description
Return a reasoned, read-only eligibility decision using current item, category, reservation, hold, member, loan, suspension, and instruction state.

== Acceptance Criteria
[source,gherkin]
----
Given an item is available and the member is eligible
When eligibility is checked
Then the response is eligible with deposit and duration
And no loan, reservation, deposit, or audit record is created
Given any issuance condition fails
When eligibility is checked
Then the response is ineligible with a stable reason
And no state changes occur
----
