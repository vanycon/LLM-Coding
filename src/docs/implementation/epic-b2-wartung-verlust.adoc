= EPIC-B2: Wartung & Verlust
:toc:

Seltene Pfade, bauen auf EPIC-B auf. Kein Blocker für den Regelbetrieb.

== User Story B2.1 — Wartung abschließen (UC-05)

Als *Wart* möchte ich eine fällige Wartung abschließen und den Nutzungszähler
zurücksetzen, damit der Gegenstand wieder ausgegeben werden darf.

* Referenz: UC-05 (`spec-use-cases.adoc`), BR-WAR-02 bis BR-WAR-04
  (`spec-domain-model.adoc`).
* Akzeptanzkriterien: `wartung-abschliessen.feature`.
* Priorität: *Could*.
* Abhängigkeit: benötigt EPIC-B (Nutzungszähler wird beim Prüfabschluss fortgeschrieben).

== User Story B2.2 — Verlust melden (UC-06)

Als *Wart* möchte ich einen Gegenstand als verloren melden können, damit er aus dem
verfügbaren Bestand entfernt wird und die Kautionsfrage geklärt werden kann.

* Referenz: UC-06 (`spec-use-cases.adoc`).
* Akzeptanzkriterien: `verlust-melden.feature`.
* Priorität: *Could*.
* Abhängigkeit: benötigt EPIC-A (eine laufende Ausleihe muss existieren, aus der heraus der
  Verlust gemeldet wird).

== Reihenfolge

B2.1 und B2.2 sind voneinander unabhängig, beide nach EPIC-B einordenbar.
