== Description
Represent member suspension, simultaneous-loan count, and documented category instruction as system-owned state used by eligibility and issue decisions.

== Acceptance Criteria
[source,gherkin]
----
Given a member has overdue unreturned loans
When the system evaluates the member
Then the member is suspended
Given all overdue loans have completed inspection
When the system recalculates the member
Then the suspension ends
And instruction records are category-specific
And awaiting-inspection loans count toward the three-loan limit
----
