== Description
Provide the local transactional persistence schema, migrations, configuration, and single-process start path required to run release 1 without external services.

== Acceptance Criteria
[source,gherkin]
----
Given a fresh local data directory
When the application is started
Then it creates or migrates the schema for catalog, members, loans, returns, inspections, deposits, holds, reservations, and audit entries
And the REST API and technician CLI can use the same data store
Given a state-changing use case writes domain state and required audit or deposit records
When the transaction commits
Then all records are durable and queryable
Given the transaction fails
When rollback completes
Then no partial domain, audit, or deposit state remains
Given the configured local process is started without external services
When a client invokes the documented interfaces
Then the system is operational from the local deployment
----
