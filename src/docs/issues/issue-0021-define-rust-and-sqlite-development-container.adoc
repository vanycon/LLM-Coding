== Description
Provide a reproducible development container with the Rust stable toolchain and the SQLite command-line and native development support required by the selected architecture.

== Acceptance Criteria
[source,gherkin]
----
Given a developer opens the repository in a Dev Container
When the container is built
Then Rust, Cargo, rust-analyzer support, SQLite CLI, SQLite headers, and pkg-config are available
And the developer can compile and test the project
Given the application uses SQLite for local persistence
When a developer runs the test suite in the container
Then temporary SQLite databases and schema migrations can be created
And the container requires no external database service
Given the development container is recreated
When the same repository is opened
Then the toolchain and database prerequisites are reproducible from version-controlled configuration
----
