== Description
Store categories and items with unique identifiers, replacement values, lifecycle status, usage counters, loan duration, maintenance interval, and instruction requirement.

== Acceptance Criteria
[source,gherkin]
----
Given a category and an item are created
When their values are persisted
Then the item belongs to exactly one category
And duration and maintenance interval are positive
And replacement value is positive
And inventory number is unique
And usage counter starts non-negative
----
